# IDEAL AI Kids Teacher

A simple bilingual starter website for:
- Muhammad Hamid Imran — Class 1
- Muhammad Ahmad Imran — Class 2

## Files
- `index.html` — page content
- `style.css` — design
- `app.js` — language switch and classroom interaction

## Important
This is a **starter front-end only**. It does not yet include live AI voice/video, login, cloud database, homework image analysis, or a secure parent dashboard. Do not enter children's private information into this demo. Those features need a secure backend and AI service integration.
